PROJECT 01 • PYTHON • FINANCE AUTOMATION

Turning a manual reporting process into "just press send."

A recurring finance process required multiple manual steps to identify converted policies associated with death claims, update a maintenance file, and prepare the results for distribution. I built a Python workflow to do the repetitive parts instead.

The Problem

Too many manual steps for something that happened repeatedly.

The reporting process required reviewing converted-policy information against death-claim activity and maintaining the results in an Excel file.

Each cycle involved receiving source information, retrieving the data, comparing records, updating the maintenance file, and preparing the completed information for email distribution.

None of those steps were individually impossible. There were just a lot of them.

And when a repeatable process contains a lot of manual steps, my brain eventually starts asking: "Okay... which parts of this can Python do?"

What I Built

From incoming information to a prepared email.

I developed a Python-based workflow that connected several parts of the reporting process so the repetitive work could happen automatically while keeping the final distribution step under human control.

My Approach

Automate the repetitive work. Keep judgment with the human.

Process first.

Before automating anything, I needed to understand the existing reporting logic, required inputs, expected outputs, and where manual decisions were actually necessary.

Then automate.

Python handled the repeatable data-processing, file-maintenance, and email-preparation steps, reducing the amount of manual intervention required each reporting cycle.

Validate the output.

Automation is only useful when the result is right. The workflow preserved a review point before final distribution so the output could be validated.

Make it usable.

The goal wasn't to build complicated code for the sake of complicated code. The goal was to make the process simple enough that the final action was essentially: review it, then press send.

Business Impact

Less manual handling. More repeatability.

Efficiency

Reduced repetitive manual steps across a recurring financial reporting workflow.

Consistency

Created a repeatable process for retrieving, processing, updating, and preparing financial information.

Knowledge Sharing

Demonstrated the automation to team members and stakeholders, showing how Python could improve an existing finance process.
